# Collaborative Whiteboard

Hand-drawn style collaborative whiteboard.

## Features

- Rough.js sketch rendering
- Presentation mode
- Shape library and tutorial

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Rough.js

## Getting Started

```bash
git clone https://github.com/ghostland-dev/hand-drawn-canvas-collab.git
cd hand-drawn-canvas-collab
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
